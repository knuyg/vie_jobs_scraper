While searching for a VIE job on the Business France website, I had the idea of using my data engineering skills to carry out this side project.

The idea is simple: I want to automatically retrieve the VIE positions posted on the Business France website and integrate them into a private database, which I can then use to create a graphical interface that allows me to filter the offers more easily.

Initially, I planned to do this as my first Rust project, so I could learn the basic concepts of the language. But after a few days, I decided to do it in Python first and publish it, so I would have a functional MVP; then rewrite everything in Rust later (or maybe just certain parts in Rust and run them via Python).
